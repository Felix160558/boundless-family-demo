# Boundless Classroom family prototype

This directory is a separately developed copy based on Boundless Classroom commit b9a793568caf2e45d3e11da1be6f9a58410d4434. The original repository and deployment must not be modified. The source remote has its push URL disabled.

Explicit user decisions supersede legacy root instructions for this prototype:
- First make a separate GitHub website. Hardware and experience tests are deferred.
- Restore and preserve the original homepage composition, type, star field and floating classroom. The only entrance-label change is Match to Study. Keep all visible interfaces in English.
- Keep the original preparation lounge, lights, cosmic view and restrained Common Room overlay, including clickable teacher portraits mounted on its walls. Do not replace them with a card directory or promotional landing page.
- Learning area is an informative future-feature entry only.
- Reservation uses clearly marked fictional teachers and example slots. Do not imply that real teachers are notified.
- A new 2–3 person meeting room has fixed seats, simple participant representations, a single shared example learning report, teacher-controlled pages, and optional real voice communication when a signaling service is configured.
- Use only the ISP PROGRAM / SUIS QP lettering from the supplied reference, reconstructed as the transparent vector `assets/isp-program-mark.svg` in both rooms. Preserve the purple/white hierarchy. No blue rectangle, backing plate, border, glow or new homepage logo block.
- Target Quest Browser/WebXR but do not claim headset, frame rate or live-network tests.
- Isolate config/storage from the original AI teacher gateway and data. Do not connect to original paid APIs.
- Never show simulated people as actually online. Empty seats remain waiting; offline/local preview must be explicit.
- No payments, unsolicited notifications, real student records or new paid services.
- Use local native HTML/CSS/ESM and the copied pinned Three.js. No framework needed.
- Only necessary syntax and source integration checks at this stage. No browser experience or microphone tests.
